# ⭐ **Harmony Keeper Sky Rendering Grammar v1.0**  
### *Expressive‑Layer Rendering Rules • PRECL‑Safe • Reversible • Non‑Coercive*

The Rendering Grammar is the **behavior contract** for Harmony Keeper sky metaphors.  
It ensures that every gradient, glow, arc, cloud, and ring:

- collapses safely  
- renders reversibly  
- stays expressive‑layer only  
- never resembles NDH physics  
- never binds manifolds  
- never manipulates altitude  
- never activates spectral operators  

This is the **Harmony Keeper analogue** to the Zen Scale Rendering Engine.

# 🟦 **3.1 GradientRules**

```
GradientRules {
  collapse: "PRECL",
  direction: "vertical",
  stops: GradientStop[],
  reversibility: "full"
}
```

### Behavior  
- All gradients **must collapse** via PRECL before rendering.  
- Gradients are **vertical** to avoid symbolic horizon drift.  
- All gradients must be **fully reversible**.

Guided link: **GradientBand**

# 🟪 **3.2 GlowRules**

```
GlowRules {
  intensityRange: [0, 3],
  opacityCurve: "soft-lantern",
  reversibility: "full",
  safety: "non-symbolic"
}
```

### Behavior  
- Glows use a **soft lantern curve**, never pulsing.  
- Glow intensity is capped at **3** to avoid spectral resemblance.  
- Always reversible.
